# 🎓 StudyNotion - Comprehensive EdTech Platform  
---

## 🚀 Overview  
**StudyNotion** is a **full-stack EdTech platform** built with the **MERN stack** that provides an engaging online learning experience for **students** and **educators**.  

With **secure authentication**, **scalable backend**, and **cloud-powered delivery**, it enables:  
- Course creation and management  
- Student enrollment and learning  
- Real-time notifications and email updates  

---

## ✨ Key Features  

✅ **Dual User Roles** – Separate dashboards for students & instructors  
✅ **Course Management** – Create, edit, purchase, and explore courses  
✅ **Secure Authentication** – JWT & Bcrypt for login/signup  
✅ **Password Reset System** – With email notifications (Nodemailer)  
✅ **Cloud Storage Integration** – Scalable and fast media delivery  
✅ **Scalable Backend** – Express.js + MongoDB with Mongoose ORM  
✅ **Modern UI/UX** – React + Context API + Hooks + Tailwind CSS  

---

## 🛠️ Tech Stack  

### 🎨 Frontend  
- React.js  
- Context API & React Hooks  
- Tailwind CSS  

### ⚙️ Backend  
- Node.js  
- Express.js  

### 🗄️ Database  
- MongoDB (Mongoose ORM)  

### 🔐 Authentication & Security  
- JWT (JSON Web Tokens)  
- Bcrypt.js  

### 📧 Other Integrations  
- Nodemailer (Email Services)  
- Cloud Storage (AWS S3 / Cloudinary / GCP)
